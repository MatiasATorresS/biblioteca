# Íconos

- `favicon.svg`: ícono vectorial del sitio (libro abierto, mismo trazo que la
  interfaz). Se declara con `<link rel="icon" type="image/svg+xml">`.
- `apple-touch-icon.png`: versión PNG de 180×180 para la pantalla de inicio de
  iOS/iPadOS.

El resto de los íconos de la interfaz son SVG inline en el HTML y en `js/ui.js`
para heredar el color del texto y evitar peticiones extra.
