# Imágenes

- `og-cover.png`: imagen de 1200×630 usada en `og:image` y `twitter:image`
  para las vistas previas al compartir el sitio.
- Puedes guardar aquí portadas propias (por ejemplo `portada-libro.jpg`) y
  referenciarlas desde el formulario de libros como `assets/images/portada-libro.jpg`.

Si publicas el proyecto en un dominio propio, recuerda reemplazar
`https://biblioteca-ejemplo.com` por ese dominio en las etiquetas Open Graph de
los HTML, en el JSON-LD, en `robots.txt` y en `sitemap.xml`.
